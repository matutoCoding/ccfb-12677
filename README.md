# 巡演灯光设计与场馆适配系统

浏览器本地运行的灯光设计 / 巡演场馆适配工具。TypeScript + WebGL2，工程数据全部存本机 IndexedDB，不联网、无后端。

## 运行

```bash
npm install
npm run dev        # 开发模式
npm run build      # 类型检查 + 单文件构建到 dist/index.html (全部资源内联, 可离线双击打开)
npm run serve      # 离线静态服务 dist, 默认 http://localhost:8080
npm test           # Node 测试套件 (28 个测试, 守护四个硬指标)
```

构建产物是单个 ~105KB 的 HTML（gzip 45KB），唯一运行时依赖 fflate（MVR/GDTF zip 打包）已被内联。

## 架构

```
src/
  core/            纯 TypeScript 领域逻辑, 无 DOM 依赖, 可被 Node 直接测试
    types.ts       全部数据模型
    math.ts        向量数学 + 均匀网格空间哈希 O(n)
    venueAdapt.ts  换馆比对 (空间哈希 + 承重/净空/障碍评估 + 替代建议)
    topology.ts    Art-Net 拓扑、确定性 BFS 断电模拟、超长网线、域-网口校验
    collision.ts   摇头灯包络: 球预筛 + 胶囊体线段求交, 输出碰撞角度区间
    photometric.ts 照度网格/伪彩/均匀度、摄像机曝光、PWM 条纹、CRI/CCT 肤色
    programming.ts 组联动、效果生成器、预设引用、cue 状态、盲编、分支
    inventory.ts   档期冲突、出库序列号分配、撤场核销
    quote.ts       报价、线缆长度、吊装排程、触发留档
    mvr.ts         MVR(zip)+GDTF 打包, 精确坐标表保证回导零偏差
    pdf.ts         零依赖 PDF 写入器 (内置 STSong-Light CID 中文字体)
    review.ts      评论钉与外部意见合并
    store.ts       IndexedDB 持久化 + 发布订阅 + 工程导入导出
    sampleData.ts  两馆/800 挂点/300 灯/10 节点演示数据
  engine/          自写 WebGL2 引擎 (无 three.js)
    mat4.ts        矩阵库
    renderer.ts    实例化渲染、拾取 FBO、剖切、轨道控制
    scene.ts       领域数据 -> GL 实例/线段映射、伪彩网格叠加
  ui/              无框架 hyperscript + 五个页面组件
tests/             node:test 套件, 用 --experimental-strip-types 直接跑 TS
```

### 关键设计决策

- **换馆比对锚点**：灯具吊在挂点下方数米，比对必须以源馆挂点坐标（而非灯具坐标）为锚，否则垂直高差会导致全部误判。
- **断电模拟确定性**：从控台做 BFS 求可达集，结果只依赖拓扑连接关系，与节点/链路存储顺序无关（测试里专门打乱顺序验证）。
- **MVR 零偏差**：标准 MVR XML 的 Matrix 是有限小数，第三方交换照写；本系统往返额外携带 `tld_exact_xyz.json` 双精度坐标表，回导优先读它，偏差恒为 0。
- **性能**：所有规模敏感路径（换馆、干涉、近邻）都走空间哈希，避免 O(n²)；碰撞检测把与姿态无关的枢轴距离预计算到采样循环外。
- **离线**：无任何外部 CDN/字体/接口；PDF 中文用 PDF 规范内置 CID 字体，不携带字体文件。
