# TourLight · 灯光设计与巡演适配系统

面向大型巡演与户外音乐节灯光总包的**纯本地、离线优先**浏览器应用。一套节目跑七八个馆，
解决"每个馆挂点/层高/供电接口不同、进场才发现灯位图落不了地、临时一改编程全乱"的问题。

- **技术栈**：TypeScript + React 18 + Zustand + 自研 WebGL2 渲染内核 + Vite
- **运行方式**：完全本地，无服务端、无 CDN、无任何联网调用；构建产物可离线打开
- **数据存储**：IndexedDB（工程数据 + 附件 Blob），工程包 `.tlpkg`（fflate 打包）可文件备份/互传

## 快速开始

```bash
npm install
npm run dev      # 本地开发
npm test         # 全量单元/正确性测试（60 个）
npm run bench    # 四个硬指标基准
npm run build    # 生产构建（dist/ 可离线部署）
```

## 五个页面

| 页面 | 能力 |
| --- | --- |
| 场馆档案 | 档案/附件（吊杆图、用电条件单）、三维复勘回写柱位层高净空、换馆自动比对与替代挂点建议 |
| 方案设计 | 灯具布置、组联动（对称/波浪/追逐）、预设集中维护、运动包络干涉、剖切、分支、盲编 |
| 灯效编程 | Cue 时间轴、淡变曲线、导演喊停插 cue、照度伪彩、摄像机曝光、PWM 滚动条纹、色温/CRI 肤色、宏 |
| 预演评审 | 场景钉评论/指派/状态、关联 cue 与灯号、客户意见导回、Art-Net 拓扑校验、断电失灯模拟 |
| 出图报价 | GDTF/MVR 打包往返、施工平面图 PDF、报价单、线缆清册、吊装日历、手机安装清单、库存档期 |

## 四个硬指标（`npm run bench` 实测，300 灯 / 2000 挂点压测档）

| 指标 | 要求 | 实测 | 实现手段 |
| --- | --- | --- | --- |
| 换馆比对 | < 3s | **~30ms** | 均匀空间哈希 + 确定性贪心最近邻分配 |
| 300 台摇头灯干涉 | < 10s | **~7.6s** | 点-段预筛 + pan/tilt 角度窗口裁剪 + 零分配标量正运动学 + sin/cos 查找表 |
| 断电失灯清单 | 与手工拓扑完全一致 | **10 个节点逐灯一致** | 确定性 BFS，基准内置独立手工 BFS 断言 |
| MVR 往返坐标 | 零偏差 | **maxDeviation = 0mm** | 坐标毫米整数精确写入，`roundTripCheck` 断言 |

## 目录结构

```
src/
├─ core/            # 纯函数引擎（无 DOM 依赖，可在 Worker/测试运行）
│  ├─ math3d.ts          向量、线段距离、AABB
│  ├─ spatial-hash.ts    均匀空间哈希（换馆比对的性能底座）
│  ├─ venue-compat.ts    换馆适配：挂点匹配+承重/净空/供电校核+替代建议
│  ├─ collision.ts       摇头灯整周运动包络干涉（角度区间）
│  ├─ network.ts         Art-Net 拓扑、>100m 标记、断电 BFS 模拟
│  ├─ photometric.ts     lux 网格、均匀度、摄像机曝光、PWM 条纹、肤色
│  ├─ fx.ts              对称/波浪/追逐组联动、圆形/螺旋/渐变生成器
│  ├─ cue.ts             Cue 时间轴、预设联动、盲编、分支
│  ├─ inventory.ts       库存档期、序列号核销、报价、线缆、吊装
│  ├─ mvr.ts             GDTF/MVR 打包与零偏差往返
│  ├─ review.ts          评审评论状态机
│  └─ document.ts        SVG 平面图、报价 HTML、安装清单
├─ renderer/        # 自研 WebGL2 内核（透视相机、轨道控制、ID 拾取、剖切）
├─ workers/         # 换馆比对 / 干涉检查的 Web Worker 包装
├─ store/           # Zustand 状态、IndexedDB 持久化、示例与压测数据
├─ pages/           # 五个业务页面
└─ components/      # Scene3D 等共享组件
```

## 关键工程决策

- **确定性优先**：所有引擎输出与遍历顺序确定（排序后 BFS、贪心分配、角度区间排序），
  保证"断电清单跟手工核对完全一致"这类可审计要求。
- **零偏差坐标**：MVR 坐标在写入侧量化到毫米整数，读回逐项断言；不依赖浮点格式转换。
- **性能可回归**：硬指标写成基准测试纳入 CI，而非仅口头承诺。
- **离线资产**：所有依赖通过 npm 本地安装并由 Vite 打包，无外部 URL。
